# Chalo Chalein - Travel Agency Website

A Next.js travel booking platform featuring Kerala getaways, Kashmir treks, and adventure packages.

## Features
- Destination pages (Kerala, Kashmir, etc.)
- Trip packages with pricing
- Responsive design
- Contact/booking system
- SEO optimized

## Tech Stack
- Next.js 14
- React 18
- Tailwind CSS
- TypeScript

## Installation
```bash
git clone https://github.com/[your-username]/chalo-chalein.git
cd chalo-chalein
npm install
npm run dev
